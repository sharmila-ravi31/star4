
# Star Catcher – Postmortem Report

## 1. Project Overview
Star Catcher is a simple arcade game developed using HTML, CSS and JavaScript.

## 2. Project Objective
The objective is to create a playable game with scoring, progression, feedback, accessibility and persistence.

## 3. Features Completed
- Game start and restart
- Pause and resume
- Score tracking
- Level progression
- Lives management
- High score persistence
- Sound effects
- Particle effects
- Keyboard controls
- Mobile controls
- Reduced motion setting

## 4. Challenges
1. Implementing collision detection.
2. Managing different game states.
3. Saving the high score.
4. Implementing keyboard and touch controls.
5. Managing sound and visual effects.

## 5. Solutions
- Used JavaScript for collision detection.
- Used game-state variables to manage transitions.
- Used Local Storage to save settings and high scores.
- Added keyboard and pointer event listeners.
- Used Canvas API for game rendering.

## 6. Learning Outcomes
- Learned basic game development.
- Improved JavaScript programming skills.
- Understood game-state management.
- Learned Local Storage.
- Improved debugging skills.
- Understood responsive design and accessibility.

## 7. Future Enhancements
- Add background music.
- Add new game modes.
- Add more levels and obstacles.
- Add a leaderboard.

## 8. Conclusion
The Star Catcher project demonstrates a browser-based game
with scoring, progression, persistence, accessibility and
interactive gameplay.
