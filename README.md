
# ⭐ Star Catcher Game

## Project Overview
Star Catcher is a browser-based arcade game developed using HTML, CSS and JavaScript.

The player controls a basket and catches falling stars to earn points.

## Features
- Score tracking
- Three levels of progression
- Three lives
- Win and Game Over screens
- Pause and Resume
- Restart game
- High score saved using Local Storage
- Sound effects
- Keyboard controls
- Mobile touch controls
- Reduced motion setting
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Canvas API
- Local Storage
- Web Audio API

## Controls
- Left Arrow / A: Move left
- Right Arrow / D: Move right
- Space: Pause or Resume
- Touch buttons: Mobile movement

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install Live Server if needed.
4. Right-click index.html.
5. Select Open with Live Server.

## Winning Condition
Catch 30 stars to reach 300 points and win the game.
